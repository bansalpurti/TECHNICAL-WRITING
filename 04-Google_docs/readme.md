Google Docs – Learning Journal
Overview
Google Docs is a cloud-based word processor included in Google Workspace. It allows users to create, edit, format and share documents online, while multiple people can work on the same document in real time.

It is useful for preparing notes, reports, proposals, meeting minutes, specifications and other general-purpose documents.
What I Learned
1. Introduction and Key Features
I learned that Google Docs supports live collaboration, rich document formatting, comments, suggestions and version history. It also allows documents to be imported and exported in formats such as DOCX, PDF, ODT, RTF, HTML and TXT.
2. Creating and Structuring Documents
I explored how to start with a blank document or use templates for reports, meeting notes and manuals. I learned to organise content using headings, paragraph styles and a clear hierarchy.

Using styles such as Title, Subtitle, Heading 1 and Normal Text helps maintain consistent formatting and can generate a table of contents automatically.
3. Collaboration and Sharing
I learned how to share a document through an email invitation or link and assign different access levels:
- Viewer: Can view the document.
- Commenter: Can add comments and feedback.
- Editor: Can make changes to the document.
I also explored Suggesting mode, comments, live cursors and integrated chat, which make it easier for multiple people to review and work on the same document.
4. Version History and Recovery
Google Docs automatically saves changes. Through File → Version history, users can review earlier versions and restore a previous state when needed. Important milestones, such as submission or approval versions, can also be named for easier reference.
5. Formatting and Inserting Content
I learned how to make documents more informative by adding:
- Tables, bulleted and numbered lists, and checklists.
- Images from uploads, camera, web, Google Drive or Photos.
- Drawings and simple diagrams using shapes and arrows.
- Equations with the built-in equation tool.
- Footnotes, links and code snippets using monospace formatting.
6. Templates, Citations and Exporting
I explored built-in templates, headers, footers and page numbering. Google Docs also provides spelling and grammar tools, find and replace, and citation features for styles such as MLA, APA and Chicago. It can insert in-text citations and generate a bibliography.

Documents can be downloaded in formats such as PDF, DOCX, ODT and HTML, or published to the web. Google Docs also integrates with other Google Workspace applications such as Slides and Sheets.
7. Permissions, Security and Integrations
I learned that access can be controlled at the document level, including setting permissions, removing access and using expiration dates. The lecture also introduces integrations with Google Drive, Calendar, Meet and Forms, as well as external tools and Google Apps Script for automation.
Best Practices I Learned
- Follow a consistent style guide and use templates where appropriate.
- Organise long documents with headings and a table of contents.
- Assign clear reviewing and editing roles.
- Resolve or clean up comments and suggestions after review.
- Name important versions and export backups of critical deliverables.
- Check sharing permissions before distributing a document.
Google Docs and Other Documentation Tools
The lecture compares Google Docs with Doxygen:
Aspect	Google Docs	Doxygen
Main purpose	General documents, proposals and notes	Code and API documentation
Collaboration	Real-time multi-user editing	Usually through code review workflows
Content	Text, images, tables and drawings	Code-linked documentation and diagrams
Output	Web, PDF, Word and other formats	HTML, LaTeX, PDF and other formats
Best suited for	Policies, specifications and notes	Source code and APIs


I understood that Google Docs is suitable for collaborative writing and general project documents, while Doxygen is designed to generate documentation from source-code comments. Both can be used together—for example, project design documents can be prepared in Google Docs while API documentation is generated with Doxygen.
Practical Learning Activity
The lecture suggests trying Google Docs collaboratively:
1. Create a document and share it with a classmate.
2. Try headings, comments and Suggesting mode.
3. Add a table and embed an image or diagram.
4. Explore version history and restore an earlier version.


Key Takeaways
Through this topic, I learned how Google Docs makes document creation, formatting and collaboration easier. I understood the importance of structured headings, styles, comments, suggestions and version history in preparing and reviewing documents. I also learned how sharing permissions, citations, export options and integrations support academic and team-based work.
